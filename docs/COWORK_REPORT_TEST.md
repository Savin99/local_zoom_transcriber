# Cowork report test

Цель: проверить, может ли Cowork делать не summary, а рабочий отчёт по
транскриптам встреч.

## Подготовка

1. Запустить watcher и получить `.md` в папке Cowork.
2. Подключить эту папку в Cowork.
3. Взять prompt из [COWORK_REPORT_PROMPT.md](COWORK_REPORT_PROMPT.md).

Для первого теста подойдёт один из длинных транскриптов:

```text
2026-01-15_10.00.00_Команда_Созвон_call_01_transcript.md
```

## Тест 1. Полный отчёт по одной встрече

Prompt:

```text
Сделай полноценный отчёт по выбранной встрече.
Используй формат из инструкции для meeting report.
```

Проверить:

- есть короткий вывод;
- есть таблицы `Решения`, `Action items`, `Открытые вопросы`, `Риски`;
- у каждого пункта есть таймкод;
- нет выдуманных владельцев и сроков;
- отчёт отражает спорные места, а не сглаживает их.

## Тест 2. Action items отдельно

Prompt:

```text
Вытащи только action items по выбранной встрече.
Для каждой задачи укажи владельца, срок, контекст и таймкод.
Не добавляй задачи, которые не следуют из транскрипта.
```

Проверить:

- обычные обсуждения не попали в задачи;
- если владелец не назван, стоит `не указан`;
- если срок не назван, стоит `не указан`;
- есть таймкоды.

## Тест 3. Спорные решения

Prompt:

```text
Найди спорные вопросы и развилки по выбранной встрече.
Для каждой развилки покажи позиции сторон, аргументы, текущий статус и таймкоды.
```

Проверить:

- Cowork не превращает спор в фальшивое решение;
- явно показывает, где решение ещё не принято;
- не теряет аргументы обеих сторон.

## Тест 4. Поиск по базе из нескольких встреч

Prompt:

```text
По всем подключённым транскриптам найди обсуждения по нескольким сквозным
темам (например: интеграции, хранилище данных, ручная верификация, объёмы
пилота). Сгруппируй по темам, укажи встречи и таймкоды.
```

Проверить:

- Cowork находит информацию из разных файлов;
- группирует по темам, а не просто пересказывает файлы подряд;
- указывает источник/дату встречи и таймкод.

## Acceptance criteria

Cowork можно использовать для отчётов, если:

- полный отчёт полезнее короткого summary;
- ключевые решения и action items можно проверить по таймкодам;
- по нескольким встречам Cowork находит повторяющиеся темы;
- нет заметных галлюцинаций по владельцам, срокам и фактам.

Если Cowork делает слишком общий текст, нужно усилить prompt:

```text
Перепиши отчёт: убери общие формулировки, добавь таймкоды к каждому пункту,
раздели решения, задачи, риски и открытые вопросы. Не добавляй информацию,
которой нет в транскрипте.
```
